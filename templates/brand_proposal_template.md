## 品牌補助 vs 研發補助的選擇邏輯

```
你的主要需求是什麼？

  新技術/服務還在開發中
    → 創新研發補助（最高500萬）

  技術/產品已有，需要市場推廣/品牌建立
    → 品牌建立補助（最高500萬）

  兩個都需要
    → 先做研發補助（建產品）→ 結案後做品牌補助（推市場）
    → 注意：不能同時執行兩案
```

### 品牌補助申請的三大關鍵

1. **一定要有營收**：無營收的新創不能申請，這是門檻
2. **委託費說明要完整**：品牌補助大量使用委託費，每個委託對象需說明資格（成立幾年、代表作品）
3. **廣告費不能列**：很多申請人把 Facebook Ads 費用列進去被退，品牌補助補的是「建立」，不是「投放」
