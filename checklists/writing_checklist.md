# 計畫書送件前自查清單

> 適用計畫：創新研發補助、創新加速補助、品牌建立補助
> 不適用：創業補助（另見 `checklists/eligibility_check.md`）、新創拔尖（梯次型）

---

## ✅ 第一關：基本資格確認（5 分鐘）

- [ ] **公司設立滿 1 年以上**（設立日距申請日 ≥ 366 天）
- [ ] **台北市登記**：公司登記地址在台北市（非虛擬辦公室、非登記服務）
- [ ] **目前無執行中的 SITI 計畫**（一次只能執行一案）
  - 若前案核定不通過，確認是否在一年內三次申請限制內
- [ ] **無欠稅/罰鍰/違約記錄**（近 3 年）
- [ ] **品牌建立補助**（額外確認）：過去一年有可查核的營業收入

---

## ✅ 第二關：計畫書核心內容（15 分鐘）

### 創新性

- [ ] **創新點說明**：明確寫出「與現有技術/服務相比，本計畫新在哪裡」
  - ❌ 錯誤範例：「本計畫採用創新的 AI 技術提升效率」（空泛）
  - ✅ 正確範例：「現有系統需人工審閱平均 3 分鐘/件，本計畫 AI 審閱準確率達 95%，處理時間壓縮至 10 秒」
- [ ] **創新三欄對照表**：現況 × 挑戰/痛點 × 本計畫如何解決（≥ 5 列）
- [ ] **不可用「首創」「唯一」等無法驗證的詞語**（會被要求佐證）

### 計畫目標

- [ ] **目標具體可量化**：包含可驗收的技術指標或服務指標
  - 例：「完成 API 整合，響應時間 ≤ 200ms，正確率 ≥ 92%」
  - 不接受：「建立良好系統」「提升服務品質」
- [ ] **目標與公司現有業務/技術基礎**有邏輯關聯（不能憑空跳躍）

### 執行計畫與查核點

- [ ] **工作拆分為 ≥ 3 個子工作項目**（Work Items）
- [ ] **甘特圖或時程表**：涵蓋整個計畫期間，各項工作有開始/結束時間
- [ ] **查核點（A/B/C/D）與可繳交產出對應**
  - 每個查核點都要有明確的「可繳交物件」（報告、程式碼、測試數據、試用名單等）
  - 查核點用量化指標（如「完成率 80%」「測試案例通過率 90%」）
- [ ] **計畫期間**：標明起迄月份，總時間 ≤ 24 個月（研發）/ ≤ 18 個月（加速/品牌）

### 市場與效益

- [ ] **市場分析段落**：有具體市場規模數字（附資料來源）
- [ ] **台北市關聯性**：說明本計畫對台北市產業/就業/稅收的貢獻
  - 「在台北市雇用 X 名員工」「在台北市服務 X 家企業客戶」
- [ ] **預估效益**有佐證，不是憑空猜測

---

## ✅ 第三關：自籌款與預算（5 分鐘）

- [ ] **自籌比例 ≥ 50%**：若申請補助 100 萬，自籌款 ≥ 100 萬
- [ ] **自籌款來源說明清楚**：公司自有資金 / 業主往來 / 其他（需具體）
  - ❌ 不可寫「尋求外部融資」（不確定性太高）
  - ✅ 可寫「公司現有帳戶存款 XX 萬」「股東增資 XX 萬（附增資決議）」
- [ ] **每筆費用都有計算基礎**：
  - 人事費：（人月數）× （月薪）= 小計，說明每人投入比例
  - 設備費/軟體費：廠牌、型號、報價單（大於 5 萬元需附）
  - 委託費：說明委託對象性質、金額計算方式
- [ ] **人事費比例**：研發類 ≤ 70%、品牌類 ≤ 60%（一般建議）
- [ ] **設備費**：❌ 不可列「辦公室裝修」「車輛購置」「不動產」

---

## ✅ 第四關：社會回饋（有薪實習）— 最高 5% 評分

- [ ] **確認已規劃至少 1 名大專院校學生有薪實習**（查核點佔 5%）
- [ ] 計畫書中已寫明：
  - 實習期間（幾個月）
  - 實習內容（具體工作，不能只寫「協助研發」）
  - 薪資水準（≥ 基本工資，建議 ≥ 28,000/月）
  - 實習生來源管道（學校合作、104、直接招募）

---

## ✅ 第五關：財務擔保（研發 / 品牌補助限定）

> 創業補助不需要；創新研發、創新加速、品牌建立需要

- [ ] 已了解「銀行履約保證金保證書」或「質權設定存單」要求
  - 金額：核定補助第一期款的 **30%**
  - 例：核定補助 200 萬，分 2 期（第一期 100 萬），需提 **30 萬** 擔保
- [ ] 已詢問往來銀行開立保證書的流程與費用（約 0.5%-1%/年手續費）
- [ ] 若財力不足以提擔保，已評估改以「質權設定存單」方式（活存轉定存）

---

## ✅ 第六關：AI 關鍵字優化（加分項）

> 根據歷史資料，含「AI」「人工智慧」的計畫補助金額較高（22% AI 案，平均高於整體均值）

- [ ] 若計畫有用到任何 AI 工具/技術，已在計畫書中明確描述
  - 包含：GPT API 應用、機器學習模型、推薦演算法、自然語言處理等
- [ ] AI 應用有具體說明（用在哪個環節、如何提升效益）
- [ ] 若完全無 AI，不強行加入（審查委員會查）

---

## ✅ 第七關：文件完整性（5 分鐘）

| 文件 | 創新研發 | 創新加速 | 品牌建立 |
|-----|---------|---------|---------|
| 申請書 | ✅ | ✅ | ✅ |
| 計畫書 | ✅ | ✅ | ✅ |
| 公司登記證明 | ✅ | ✅ | ✅ |
| 計畫人員勞保/就業保險 | ✅ | ✅ | ✅ |
| 近一年財務報表 | ✅ | ✅ | ✅ |
| 近一年所得稅+營業稅申報書 | ✅ | ✅ | ✅ |
| **營業收入實績佐證文件** | ❌ 不需 | ❌ 不需 | ✅ **必要** |

- [ ] 所有 PDF 頁面完整，無空白頁、無截切
- [ ] 公司負責人簽名/用印處已完成
- [ ] 電子申請系統上傳格式確認（官方規定 PDF/Word，個別檔案 ≤ 10MB）

---

## ✅ 第八關：常見送件失誤

- [ ] 計畫書**主詞一致**：全文使用「本計畫」或「本公司」，不混用「我們」「我司」
- [ ] **金額單位統一**：全文用「萬元」或「仟元」，不混用
- [ ] **計畫名稱**：計畫書封面、申請書、系統上傳三處名稱一致
- [ ] **計畫期間**：三處（申請書/計畫書/甘特圖）起迄日期一致
- [ ] **法定代表人**：填寫公司登記上的負責人姓名（非職稱）
- [ ] **計畫主持人**：已在公司任職且有加勞保（核查時會比對）

---

## 最後：申請前打一通電話

**SITI 諮詢電話：02-2720-8889**（週一至週五 09:00-17:00）

打電話前準備：
1. 公司設立日期（確認是否滿 1 年）
2. 計畫主題一句話說明（確認對應哪個補助類別）
3. 預計補助金額（確認是否可申請到計畫書寫的金額）

> 官方人員通常很樂意回答「這樣可以申請嗎」這類問題，**打電話比在網路上猜測更可靠**。
